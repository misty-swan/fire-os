# FireOS 導入確認チェックリスト（D01〜D20・一項目一回答）

版: v1 / 2026-10-21 / docs/16 T087。docs/14_設計判断・未決事項.md §2 の設計判断20件（D01〜D20）を、消防団の皆さまに一項目一回答で確認いただくための表です（導入提案資料は docs/ADOPTION_PROPOSAL.md）。

- **「現在の検証設定」はすべて未承認です。** 開発では推奨案を「検証設定」として実装・試験に使いましたが、業務運用の了承とは扱いません（docs/14 §2 の規定どおり）。
- **「回答」欄は空欄でお渡しします。** 回答の記録はT088（正式判定）で行います。この表に回答を書いたものとして扱いません。
- 各項目の詳細（影響する要件・画面・API・表）は docs/14_設計判断・未決事項.md §2 の該当Dが正本です。
- 「影響・意思決定者」列の SCR・API などの番号は、開発者との照合用の参照番号です。読み飛ばして構いません。
- 記入方法: 回答欄へ「了承する」「代替案を採る（内容を記載）」「要相談」等を書いてください。判断に迷うものは空欄のままでも構いません（未回答のまま正式リリースはできません: docs/13_リリース判定基準.md RG-10）。**D01は3つの機能ID（MAP-10・AI-06・AI-07）を挙げて、含める/含めないを1文に1機能で言い切る形で書いてください**（記録は文単位で読み取るため。docs/evidence/release-decision.md §5①）。
